## 1. Design System & Anti-AI Directive

### 1.1 Strict Negative Constraints (Anti-AI Guardrails)
- **Zero Emojis:** Do not render any emoji characters (no needles, thread, scissors, stars, or phone icons). Use lightweight monochrome SVG line vectors (1.5px stroke) only where strictly necessary.
- **No Synthetic Gradients:** Avoid purple, violet, indigo, or rainbow linear gradients. All background colors must represent physical, tactile materials (washed linen, stone, chalk).
- **No Pill Badges or Bulbous Containers:** Restrict `border-radius` to a maximum of `4px` (`rounded-sm`). Avoid pill buttons (`rounded-full`) and heavy floating drop shadows.
- **Asymmetrical Editorial Layout:** Avoid centered, cookie-cutter SaaS layouts. Utilize magazine-style side-by-side grids, generous whitespace, understated borders, and crisp serif headlines.

### 1.2 Color Tokens
| Token Name | Hex Code | Visual Role | Material Metaphor |
| :--- | :--- | :--- | :--- |
| `canvas-base` | `#FAF8F5` | Main document background | Unbleached Belgian linen |
| `surface-card` | `#F2EEE9` | Section surfaces / image backgrounds | Chalked limestone |
| `ink-main` | `#1A1918` | Primary headlines and high-contrast text | Charcoal tailor's chalk |
| `ink-muted` | `#635E59` | Body prose and technical specifications | Washed stone wash |
| `border-line` | `#E3DDD5` | 1px dividers, grid outlines | Hand-drawn seam baseline |
| `accent-clay` | `#8C4E37` | Active hover states, micro-accents | Terracotta craft dye |
| `accent-slate`| `#2C3947` | Primary contact buttons, nautical tags | Marine canvas navy |

### 1.3 Typography Rules
- **Headlines (`font-serif`):** `Playfair Display`, `Georgia`, or system serif. Tracking: normal to slightly loose (`tracking-tight` to `tracking-normal`).
- **Body & Captions (`font-sans`):** `Plus Jakarta Sans`, `Inter`, or `system-ui`. Line height: `leading-relaxed` (1.65+).
- **Micro Labels / Taglines:** Uppercase sans-serif with wide letter-spacing (`tracking-widest text-xs`).
